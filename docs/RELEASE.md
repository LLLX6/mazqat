# بوابات إصدار MAZQAT

## حالة النسخة 0.9.1

نسخة عامة قابلة للتجربة على الهاتف وسطح المكتب، وليست سوقًا إنتاجيًا. GitHub Pages يشغّل المعاينة المحلية فقط. حزمة Sites تبني نموذج D1 معطّلًا افتراضيًا؛ لا يُفتح إلا لتجربة فريق خاصة، ولا يصلح لمستخدمين حقيقيين.

## قبل تجربة مغلقة مع مستخدمين حقيقيين

- حسابات موثقة وسياسات RLS/RBAC لكل دور، وMFA للمالك والمنظم.
- بث LiveKit منخفض التأخير بصلاحيات تمنع المشاهد من النشر، مع اختبار شبكات وأجهزة فعلية في مسقط.
- محرك مزايدة server-authoritative: قفل/تسلسل معاملات، idempotency، منع القنص، نتيجة واحدة، وaudit لا يُمحى.
- حماية المعدل وCAPTCHA عند الحاجة، مراقبة أخطاء، نسخ احتياطي واسترجاع مجرّب.
- فصل السعر الفائز عن المبلغ المستحق والمدفوع ورسوم التوصيل والاسترداد.
- شروط الاستخدام والخصوصية والسلع الممنوعة والترخيص والضرائب والدفع وفق مراجعة قانونية عُمانية.
- اختبار ضغط وتزامن، انقطاع وإعادة اتصال، restart/redeploy، وRLS matrix كامل.

## قبل الإنتاج العام

- بوابة دفع وwebhooks موقعة، SMS/بريد إنتاجي، Push، نطاق وTLS ومراقبة تشغيلية.
- سجل موافقات وشكاوى وإلغاء مدقّق، وآلية دعم وتسوية نزاعات.
- سياسات حفظ/حذف البيانات والوسائط، ونسخ مستقل لتسجيلات البث.
- اختبار وصول WCAG عملي بالعربية، واختبارات كاميرا/بطارية/حرارة على أجهزة منخفضة ومتوسطة وعالية.

لا يجوز إزالة شارة «نسخة معاينة» أو وصف المزاد بأنه حقيقي قبل إغلاق هذه البوابات.
