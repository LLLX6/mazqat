# بوابات إصدار MAZQAT

## حالة النسخة 0.10.0

معاينة عامة قابلة للتجربة على الهاتف والكمبيوتر، وليست سوقًا إنتاجيًا. تضم بوابة الدور، تجربة المزايد، غرفة المنظّم الكاملة، ولوحة مالك الشبكة. GitHub Pages يشغّل حالة محلية داخل المتصفح فقط.

تم التحقق محليًا من:

- 9 اختبارات لمحرك المزايدة، تشمل idempotency والإغلاق المرن وإيقاف المنظّم وتمديده واختيار الزيادات والإغلاق اليدوي.
- TypeScript وESLint والبناء الثابت.
- 390×844 و1440×1000 دون تمدد أفقي غير مقصود.
- غرفة المزايد بارتفاع شاشة الهاتف كاملًا دون تمرير.
- انعكاس إعدادات المنظّم في أزرار المزايد.
- تعليق حساب منظّم وتغيير خطته وظهور القرار في التدقيق.
- عدم وجود أخطاء متصفح أو معرفات مكررة أو صور بلا `alt` أو أزرار بلا اسم.

## غير موجود في المعاينة العامة

- تسجيل دخول حقيقي أو MFA أو فصل بيانات متعدد المستأجرين.
- بث عام أو تسجيل فيديو أو مزايدة مشتركة بين الأجهزة.
- دفع أو رسائل SMS/بريد/Push أو توقيع تسليم.
- توثيق نشاط أو KYC أو سياسات سلع أو نزاعات فعلية.

## قبل تجربة مغلقة مع مستخدمين حقيقيين

- هوية موثقة، MFA للمالك والمنظّم، وRLS/RBAC لكل مساحة ودور.
- PostgreSQL بمعاملات وقفل، idempotency، rate limits، إغلاق مرن، نتيجة واحدة، وaudit append-only.
- بث منخفض التأخير بصلاحيات تمنع المشاهد من النشر وتوكنات قصيرة العمر.
- تخزين وسائط خاص بمسارات موقعة وفحص نوع/حجم/برمجيات خبيثة.
- مزود رسائل ودفع تجريبيان مع webhooks موقعة وفصل السعر الفائز عن المدفوع.
- مراقبة أخطاء ومقاييس وتأخير، نسخ احتياطي واسترجاع مجرّب، واختبار restart/redeploy.
- مراجعة قانونية داخل عُمان للترخيص والخصوصية والضرائب والسلع المحظورة والشروط.
- اختبار ضغط وتزامن وانقطاع شبكة ومصفوفة RLS واختبارات أجهزة فعلية في مسقط.

## قبل الإنتاج العام

- دفع إنتاجي وتسويات واستردادات، دعم ونزاعات، وإجراءات موافقة وتعليق قابلة للتدقيق.
- سياسات حفظ وحذف البيانات وتسجيلات البث، ونطاق وTLS ومراقبة وتنبيه على مدار التشغيل.
- WCAG عملي بالعربية واختبارات كاميرا وبطارية وحرارة على أجهزة منخفضة ومتوسطة وعالية.

لا تُزال شارة المعاينة ولا يُوصف المزاد بأنه بيع حقيقي قبل إغلاق هذه البوابات.
