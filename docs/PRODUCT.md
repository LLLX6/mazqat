# قرار المنتج — MAZQAT

## التعريف الصحيح

MAZQAT ليست مزادًا واحدًا ولا لوحة إدارة ملحقة بتطبيق تسوق. هي **منصة متعددة المنظّمين**: سوق عام للمزايدين، مساحة تشغيل مدفوعة لكل منظّم معتمد، وتحكم شبكي خاص بمالك المنصة.

الحساب الشخصي قد يكون مزايدًا وعضوًا في مساحة أو أكثر. المساحة مؤسسة مستقلة لها خطة ومقاعد وأدوار ومزادات وكتالوج وسجل خاص بها.

## باب الدخول

- **أريد المزايدة والشراء:** دخول مباشر إلى الاكتشاف والمزاد والنشاط والحساب.
- **أريد تنظيم مزادات:** رمز دعوة أو تجربة حساب منظّم أو طلب اشتراك يخضع للموافقة.
- **مالك المنصة:** وصول خاص إلى الشبكة؛ لا يظهر كدور تجاري للمستخدم العادي.

## خريطة التجارب

| المزايد | المنظّم | المالك |
|---|---|---|
| لك | اليوم | نظرة عامة |
| المعروضات | مزاداتي | المنظّمون |
| مباشر | غرفة التحكم | الخطط |
| فوزي | المخزون | التدقيق |
| حسابي | مساحتي | الحساب |

## غرفة المنظّم

غرفة التحكم هي قلب المنتج، وفيها أربع طبقات:

1. **البث والمزايدة:** برنامج الكاميرا، السعر، المؤقت، إيقاف/استئناف، تمديد، زيادات، وإغلاق.
2. **ترتيب القطع:** Rundown واضح بالجاهزية والسعر والصورة والقطعة التالية.
3. **المزايدون والفريق:** حالة المؤهلين والمشاهدين، أعلى المزايدين، وأدوار العاملين دون حساب مشترك.
4. **النتائج والتسليم:** انتقال الفائز إلى طلب خاص، اختيار الاستلام، حالات المتابعة، وسجل النتيجة.

## نموذج الربح

- اشتراك مساحة منظّم بعد موافقة المالك.
- خطط بعدد مقاعد مسماة: ٤ / ١٠ / ٥٠؛ الدعوات المعلّقة تحجز مقاعد.
- رسم إعداد أو تفعيل اختياري.
- عمولة اختيارية على البيع المكتمل فقط، لا على سعر فائز غير محصل.
- إضافات مدفوعة مستقبلًا: غرف متزامنة، فروع، تخزين تسجيلات، وتحليلات متقدمة.

لا تباع كلمة مرور مشتركة. كل شخص له حساب ودور ونطاق، والمالك لا يعدّل نتيجة مزاد بصمت.

## دورة حياة المنظّم

```text
طلب جديد → مراجعة الهوية والنشاط → موافقة وخطة → دعوات ومقاعد
          → تشغيل مزادات → تجديد أو ترقية → تعليق بسبب موثّق عند الحاجة
```

## مبادئ التجربة

- الهاتف أولًا للمزايد وللمضيف، مع غرفة مزاد لا تحتاج تمريرًا أثناء الجولة.
- أفعال قليلة وواضحة في اللحظات الحرجة؛ لا دردشة عامة ولا مزايدة مؤجلة عند الانقطاع.
- الألوان حالات تشغيلية: المرجاني للمباشر والخطر، التركواز للقبول والتصدر، الذهبي للقرار والمراجعة.
- الاسم المستعار والسعر يظهران في الترتيب؛ البيانات الشخصية تبقى خاصة.
- كل نجاح في المعاينة يصف نفسه كمعاينة ولا يوحي بدفع أو بيع حقيقي.

## ثوابت لا تُكسر

- الخادم في الإنتاج هو مصدر السعر والوقت والحالة والفائز.
- idempotency لكل عرض، وإصدار/قفل يمنع قبول سعر قديم.
- لا حذف لعرض مقبول من واجهة المضيف.
- لا فتح بث أو دعوة أعضاء خارج استحقاقات الخطة.
- لا اختلاط بيانات أو وسائط بين مساحات المنظّمين.
- السعر الفائز، المبلغ المستحق، المدفوع، ورسوم التسليم حقول مستقلة.
