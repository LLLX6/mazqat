# قرار المنتج المختصر

MAZQAT يركز على مزاد حي واضح بدل دردشة مشتتة. المشاهد يرى القطعة والسعر والوقت، ثم يضغط واحدة من زيادات محددة مسبقًا. أعلى ثلاثة مزايدين يظهرون بأسماء مستعارة، والفائز يستلم رسالة نظام خاصة بدل مشاركة بياناته علنًا.

## مبادئ الواجهة

- الإطار هادئ وفاتح، والهوية كحلية–تركوازية مع ذهبي للقطع المميزة.
- المرجاني للمباشر والوقت الحرج، النعناعي للنجاح والتصدر، والأزرق للمعلومة والموعد.
- الإيموجي في عناوين الأقسام والبلاطات وأزرار القرار، لا في كل جملة.
- الهاتف أولًا: 3×2 أقسام، أزرار لمس كبيرة، تنقل سفلي ثابت، ومساحة آمنة تحته.
- لا عرض ناجح وهمي: عند غياب الخادم تعمل المعاينة محليًا وتقول ذلك بوضوح.

## رحلة المزاد

```text
اكتشف → افهم حالة القطعة → ادخل البث → راجع السعر → أكّد الزيادة
       → شاهد ترتيبك → إغلاق موثوق → رسالة فوز خاصة → استلام/توصيل
```

## ما لا نفعله

- لا دردشة عامة للمشاهدين.
- لا مزايدة مؤجلة أثناء انقطاع الشبكة.
- لا إلغاء صامت لعرض مقبول.
- لا تخزين API أو الرسائل الخاصة داخل Service Worker.
- لا مساواة بين السعر الفائز والمبلغ المدفوع.
