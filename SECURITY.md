# Security policy

MAZQAT is currently an interactive preview, not a live marketplace. Do not enter real payment, identity, address, or inventory data.

Report vulnerabilities privately through the repository's **Security → Report a vulnerability** flow. Include the affected route, reproduction steps, and impact. Do not open a public issue containing personal data or an exploit against a live user.

The public preview has no payment flow, no production authentication, and no real video broadcast. The anonymous D1 demo route is disabled by default and must not be exposed to public traffic. Those capabilities must not be enabled before the production gates in `docs/RELEASE.md` are complete.
