# مزاد مسقط — MAZQAT

MAZQAT شبكة مزادات حيّة مُدارة ومتعددة المنظّمين: المزايد يكتشف ويشارك، المنظّم المعتمد يدير مزاداته من مساحة خاصة، ومالك المنصة يتحكم في الحسابات والخطط والصلاحيات والتدقيق.

> الإصدار الحالي **معاينة تفاعلية ببيانات وهمية**. لا يوجد بيع أو دفع أو بث عام أو حسابات حقيقية، ولا ينبغي إدخال بيانات شخصية حقيقية فيه.

## ثلاث تجارب منفصلة

- **المزايد:** اكتشاف وبحث، غرفة بث بلا دردشة، زيادات رقمية يحددها المنظّم، أعلى ثلاثة مزايدين، انسحاب إلى وضع المشاهدة، فوز وتسليم.
- **المنظّم:** لوحة يومية، مزادات وكتالوج وفريق وخطة، وغرفة تحكم خاصة للبث والقطع والمزايدين والنتائج.
- **مالك المنصة:** قبول المنظّمين أو رفضهم، خطط ٤/١٠/٥٠ مقعدًا، فتح ملف أي مساحة، تعديل صلاحياتها أو تعليقها، وسجل تدقيق للقرارات.

## غرفة تحكم المنظّم

غرفة التحكم تشارك نفس حالة المزاد التي يراها المزايد في المعاينة. يستطيع المضيف:

- تشغيل معاينة الكاميرا وتعديل الفلاتر وتخطيط المشهد محليًا.
- إيقاف المزايدة واستئنافها دون حذف العروض المقبولة.
- تمديد الوقت ٣٠ ثانية وتطبيق الإغلاق المرن في الثواني الأخيرة.
- اختيار أزرار +١ / +٥ / +١٠ ر.ع. التي تظهر للمزايدين.
- إغلاق الجولة عبر تأكيد واضح وتثبيت أعلى عرض في مسار واحد.
- تجهيز القطعة التالية ومراقبة الطابور وأعلى المزايدين وسجل الغرفة.
- فصل صلاحيات المضيف ومدير الكتالوج وموظف التسليم.

## التشغيل المحلي

يتطلب Node.js 22.13 أو أحدث؛ تستخدم CI إصدار Node 24.

```bash
npm ci
npm run dev
```

افتح `http://127.0.0.1:4173/`، أو استخدم روابط المعاينة المباشرة:

- `?view=bidder#bidder-home`
- `?view=organizer#partner-control`
- `?view=owner#owner-home`

```bash
npm run check          # 9 اختبارات + TypeScript + ESLint
npm run build:static   # حزمة GitHub Pages داخل static-dist
npm run build          # حزمة Vinext/OpenAI Sites على Linux
```

## حدود الصدق التشغيلي

GitHub Pages يحفظ الحالة داخل جلسة المتصفح فقط. نموذج `/api/auction` معطّل افتراضيًا ولا تستخدمه المعاينة العامة؛ لا يضم تسجيل دخول إنتاجيًا ولا تعدد مستأجرين ولا إغلاقًا زمنيًا موثوقًا. لا يجوز فتحه للعامة.

الإنتاج الحقيقي يحتاج قاعدة PostgreSQL موثوقة بسياسات RLS/RBAC، هوية وMFA للمالك والمنظّم، بثًا منخفض التأخير بتوكنات قصيرة العمر، محرك مزايدة server-authoritative، دفعًا ورسائل موقعة، مراقبة ونسخًا احتياطية، وسياسات قانونية وتشغيلية عُمانية. التفاصيل في [docs/RELEASE.md](docs/RELEASE.md).

## قاعدة الثقة

```text
المزايد ── عرض + idempotency ──> خادم المزاد ── معاملة/قفل ──> سجل العروض
                                                   ├─> سعر ووقت موحدان
                                                   ├─> نتيجة واحدة
                                                   └─> تدقيق لا يُمحى من الواجهة

المضيف ── فيديو ──> خادم البث ──> المشاهدون
المالك ── سياسات المستأجر والخطة ──> صلاحيات كل مساحة
```

السعر يُخزّن بالبيسة كعدد صحيح. لا يعتمد قبول العرض أو إغلاق الجولة على ساعة الهاتف، ولا يستطيع المضيف تعديل عرض مقبول أو استبدال الفائز بصمت.
